WorldCast:
World-Consistent Character Video Generation with Large-Angle Camera Control

Sections

    Hi there,

    We are excited to present WorldCast , a framework for world-consistent character video generation under large-angle camera motions. Given an initial frame and a target camera trajectory that combines rotation, translation, radius variation, and arbitrary initial azimuths, WorldCast synthesizes a video that faithfully follows the camera path while preserving the character's geometry, appearance, and identity across viewpoints.



    Large-angle viewpoint changes expose character regions unseen in the initial frame, leading to geometric distortion, appearance degradation, and identity drift. WorldCast tackles these coupled challenges with explicit 3D guidance: it back-projects the initial frame into a point cloud with estimated depth, aligns the cloud's scale to the target trajectory, and renders it along the path to obtain geometric guidance and coverage masks. To complement the incomplete character information, we introduce Geometry-Aligned Memory Attention (GAMA), which retrieves and injects view-relevant character features from multi-view anchors expressed in a shared coordinate frame.
